Documentation for this format

Options Sets

Answer options for staffing-level

  • RN/MA + MD
  • RN champion + PharmD
  • Multidisciplinary team (RN, PharmD, social worker, CHW)

Answer options for chw-program

  • No CHW program documented
  • High-risk patients only
  • Full integration across all HF patients

Answer options for monitoring-tech

  • Analog only (telephone, paper diary)
  • Dual-track (analog and digital available based on patient)
  • Digital primary plus remote patient monitoring (RPM)

Answer options for financial-navigation

  • Generic Bridge pathway only (low-cost generics)
  • Patient assistance program (PAP) pursuit plus Generic Bridge
